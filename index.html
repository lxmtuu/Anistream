Chạy app Flutter

Trên máy của bạn
Cần Flutter ≥ 3.22. Repo đã có sẵn thư mục platform — đừng chạy flutter create.
git clone https://github.com/lxmtuu/Anistream
cd Anistream/app
flutter pub get
flutter run -d chrome   # hoặc -d windows / -d <mã điện thoại>
CI: flutter analyze + flutter test tự chạy mỗi lần sửa app/
Dữ liệu: metadata từ AniList / Kitsu / TMDB (không host video) · video do các kênh official đăng công khai, nhúng bằng trình phát chính thức · nền tảng khác (Netflix, Crunchyroll…) mở bằng deep link.
AniStream không lưu trữ, không trích xuất, không phát lại video của bên thứ ba.
